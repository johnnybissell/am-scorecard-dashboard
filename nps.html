How to keep this dashboard auto-updating
Step 1 — Google Sheet
Seed the master ledger with your historical data
Create a Google Sheet named NPS Master with a tab called raw. Upload your historical CSV export from ChurnZero (Export_10556.csv) as the starting data. The sheet needs these columns exactly:

Scheduled Survey Date | Response Date | Contact Full Name | Contact Email | Account Name | Account Owner | Response Source | Score | Follow-Up Response | Account Primary Practice Area | Account Avg Monthly Lead Volume (Lifetime) | Account Total Contract Amount | Account Account Executive
Step 2 — Zapier Zap
Trigger: New message in Slack NPS channel → Append row to Google Sheet
Build this Zap in Zapier (you already have it connected):

Trigger: Slack → New Message Posted to Channel → select your NPS channel

Action 1: Zapier Formatter → Text → Extract Pattern — use a separate formatter step for each field below. Or use a single Utilities → Line-item to Text step if ChurnZero sends labeled key:value lines.

Map these fields from the Slack message to the Sheet columns: 
Score            → Column H (Score)
Account Name     → Column E (Account Name)
Contact Name     → Column C (Contact Full Name)
Contact Email    → Column D (Contact Email)
Account Owner    → Column F (Account Owner)
Practice Area    → Column J (Account Primary Practice Area)
Lead Volume      → Column K (Account Avg Monthly Lead Volume)
TCA              → Column L (Account Total Contract Amount)
Account Exec     → Column M (Account Account Executive)
Comment/Feedback → Column I (Follow-Up Response)
Response Date    → Column B (set to today's date)
Source           → Column G (hardcode "Slack")
Before building: paste a sample NPS Slack message here and I'll write the exact regex patterns for each field. The field names in the message need to match what ChurnZero sends.
Step 3 — Apps Script
Auto-compute aggregates and push updated JSON to GitHub
In your Google Sheet → Extensions → Apps Script. Paste this script. It runs on a daily trigger, recomputes all NPS aggregates from the raw tab, and commits the updated nps_data.json to your GitHub repo — which instantly updates this dashboard. 
// NPS Dashboard — Apps Script
// Runs daily at 6am PT. Reads raw tab, recomputes all aggregates,
// pushes updated nps_data.json to GitHub Pages repo.

const GITHUB_TOKEN = PropertiesService.getScriptProperties().getProperty('GITHUB_TOKEN');
const GITHUB_REPO  = 'johnnybissell/am-scorecard-dashboard';
const GITHUB_FILE  = 'nps_data.json';
const SHEET_NAME   = 'raw';

function runDailyUpdate() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(SHEET_NAME);
  const data = sheet.getDataRange().getValues();
  const headers = data[0];
  const rows = data.slice(1).filter(r => r[7] !== '' && r[7] !== null);

  function col(name) { return headers.indexOf(name); }
  const iScore = col('Score');
  const iDate  = col('Response Date');
  const iPA    = col('Account Primary Practice Area');
  const iOwner = col('Account Owner');
  const iAE    = col('Account Account Executive');
  const iLead  = col('Account Avg Monthly Lead Volume (Lifetime)');
  const iTCA   = col('Account Total Contract Amount');
  const iComment = col('Follow-Up Response');

  function parseScore(v) {
    const n = parseInt(v);
    return isNaN(n) ? null : n;
  }

  function quarter(d) {
    if (!d) return 'Unknown';
    const dt = new Date(d);
    if (isNaN(dt)) return 'Unknown';
    return `${dt.getFullYear()}-Q${Math.floor(dt.getMonth()/3)+1}`;
  }

  function npsCalc(scores) {
    const valid = scores.filter(s => s !== null);
    if (!valid.length) return {nps:null,n:0,promoters:0,passives:0,detractors:0};
    const p = valid.filter(s=>s>=9).length;
    const d = valid.filter(s=>s<=6).length;
    const pa = valid.length - p - d;
    return {
      nps: Math.round((p-d)/valid.length*1000)/10,
      n: valid.length, promoters:p, passives:pa, detractors:d,
      pct_p: Math.round(p/valid.length*1000)/10,
      pct_pa: Math.round(pa/valid.length*1000)/10,
      pct_d: Math.round(d/valid.length*1000)/10,
      avg_score: valid.length ? Math.round(valid.reduce((a,b)=>a+b,0)/valid.length*100)/100 : null
    };
  }

  function leadBucket(v) {
    const n = parseFloat(String(v).replace(/,/g,''));
    if (isNaN(n)) return 'Unknown';
    if (n===0) return '0';
    if (n<25) return '1-24';
    if (n<75) return '25-74';
    if (n<200) return '75-199';
    return '200+';
  }

  function tcaBucket(v) {
    const n = parseFloat(String(v).replace(/[$,]/g,''));
    if (isNaN(n)) return 'Unknown';
    if (n<1000) return '<$1K';
    if (n<3000) return '$1K-$3K';
    if (n<6000) return '$3K-$6K';
    if (n<12000) return '$6K-$12K';
    return '$12K+';
  }

  const parsed = rows.map(r => ({
    score: parseScore(r[iScore]),
    quarter: quarter(r[iDate]),
    practice: (r[iPA]||'').trim() || 'Unknown',
    owner: (r[iOwner]||'').trim() || 'Unknown',
    ae: (r[iAE]||'').trim() || 'Unknown',
    leadBucket: leadBucket(r[iLead]),
    tcaBucket: tcaBucket(r[iTCA]),
    comment: (r[iComment]||'').trim()
  }));

  const quarters = [...new Set(parsed.map(r=>r.quarter))].filter(q=>q!=='Unknown').sort();

  function groupBy(arr, key) {
    return arr.reduce((acc,r) => { (acc[r[key]]=acc[r[key]]||[]).push(r); return acc; }, {});
  }

  const byQ = groupBy(parsed, 'quarter');
  const byPA = groupBy(parsed, 'practice');
  const byOwner = groupBy(parsed, 'owner');
  const byAE = groupBy(parsed, 'ae');

  const result = {
    quarters,
    by_quarter: Object.fromEntries(quarters.map(q => [q, npsCalc((byQ[q]||[]).map(r=>r.score))])),
    by_practice: Object.fromEntries(Object.entries(byPA).filter(([,v])=>v.length>=5).map(([k,v])=>[k,npsCalc(v.map(r=>r.score))])),
    by_owner: Object.fromEntries(Object.entries(byOwner).filter(([,v])=>v.length>=5).map(([k,v])=>[k,npsCalc(v.map(r=>r.score))])),
    by_ae: Object.fromEntries(Object.entries(byAE).filter(([,v])=>v.length>=5).map(([k,v])=>[k,npsCalc(v.map(r=>r.score))])),
    // QoQ by dim (trimmed for brevity — same pattern as above, group by dim x quarter)
    by_lead_bucket: Object.fromEntries(['0','1-24','25-74','75-199','200+','Unknown'].map(b=>[b,npsCalc(parsed.filter(r=>r.leadBucket===b).map(r=>r.score))])),
    by_tca_bucket: Object.fromEntries(['<$1K','$1K-$3K','$3K-$6K','$6K-$12K','$12K+','Unknown'].map(b=>[b,npsCalc(parsed.filter(r=>r.tcaBucket===b).map(r=>r.score))])),
    meta: {
      total_responses: parsed.length,
      last_updated: new Date().toISOString().slice(0,10),
      quarters
    }
  };

  // Push to GitHub
  const existing = getGitHubFile_();
  const payload = JSON.stringify({
    message: `NPS data update ${result.meta.last_updated}`,
    content: Utilities.base64Encode(JSON.stringify(result)),
    sha: existing.sha
  });
  UrlFetchApp.fetch(`https://api.github.com/repos/${GITHUB_REPO}/contents/${GITHUB_FILE}`, {
    method: 'PUT',
    headers: {'Authorization':'token '+GITHUB_TOKEN,'Content-Type':'application/json'},
    payload
  });
  console.log('NPS data updated:', result.meta.last_updated);
}

function getGitHubFile_() {
  const res = UrlFetchApp.fetch(`https://api.github.com/repos/${GITHUB_REPO}/contents/${GITHUB_FILE}`, {
    headers: {'Authorization':'token '+GITHUB_TOKEN}
  });
  return JSON.parse(res.getContentText());
}

// Run daily at 6am PT — set up with:
// ScriptApp.newTrigger('runDailyUpdate').timeBased().atHour(6).everyDays(1).create()

Quarter-over-quarter written analysis

Written synthesis of detractor feedback patterns each quarter, cross-referenced by TCA tier, lead volume, and practice area. Based on comments from customers who scored 0–6 and left written feedback.

2025 Q1 NPS +38.1 97 responses · 17 detractor comments
The highest-performing quarter in the dataset. Complaints were diffuse with no single dominant theme — a healthy sign that no systemic failure had taken hold. Detractors were evenly split between ease of use / UX, product gaps, bugs, and support access. Small sample sizes per theme make it hard to draw firm conclusions, but the pattern points to individual friction points rather than structural problems.
By TCA tier
Detractors were concentrated in <$1K TCA (10 of 17). Their complaints leaned toward product gaps and UX — consistent with lower-investment firms who haven't unlocked full platform value. The $1K–$3K tier cited support access more, suggesting mid-tier firms were hitting walls when they needed help configuring the product.
By lead volume
0-lead firms (likely inactive or early-stage) complained most about support access. 25–74 lead firms hit onboarding friction — mid-volume firms with enough complexity to need setup help but not enough scale to have dedicated staff for it. High-volume (200+) firms were quiet, with only scattered reliability mentions.
By practice area
Low detractor counts across all practices — no single area was a problem. Estate Planning had the most detractors (2), focused on UX. Business Law flagged bugs and support. No red flags by practice area this quarter.
Top signal
One comment stands out as a leading indicator: "The core functionality hasn't changed in six years... Marketing tracking is still not good. Doc automation isn't good enough." This product staleness complaint would grow louder in subsequent quarters.
Ease of use / UX 24% Product gaps 24% Bugs 18%
2025 Q2 NPS +22.6 195 responses · 35 detractor comments ▼ 15.5 pts from Q1
The first significant drop — NPS fell 15.5 points as response volume doubled. Product gaps became the dominant complaint at 43%, nearly doubling the share from Q1. Bugs and UX complaints also grew. This is the quarter where the gap between what customers expected and what the platform delivered became visible at scale. Support access complaints were high (17%), likely reflecting a support team not scaled to match customer growth.
By TCA tier
The <$1K tier (26 of 35 detractors) drove both product gaps (12 comments) and bugs (7). These are small firms with low contract value but high frustration — a churn-prone cohort. The $3K–$6K tier showed up briefly with product gap complaints, a notable signal that even higher-investment firms were hitting feature ceilings. Mid-tier ($1K–$3K) split between UX and bugs.
By lead volume
Product gaps were the top complaint across every lead volume tier — no bucket was spared. Low-volume (0-lead) firms split between bugs and product gaps. The 25–74 lead tier had the highest product gap concentration (4 of 7 detractors), suggesting mid-volume firms were actively trying to build workflows and running into missing functionality.
By practice area
Estate Planning emerged as the largest detractor source (11 comments) with UX and product gaps leading. Business Law was disproportionately negative, driven by bugs and feature gaps. This is also when Business Law's NPS hit −60, its lowest point. Bankruptcy firms (small n) flagged product gaps and UX.
Top signal
"Every firm I work with that uses you complains about ease of use. It is so hard to manage everything in the current interface. Also, very limited options and features." — A consultant speaking for multiple firms. This is the kind of comment that compounds: one dissatisfied consultant poisons multiple pipeline accounts.
Product gaps 43% Bugs 26% UX 23%
2025 Q3 NPS +29.2 178 responses · 27 detractor comments ▲ 6.6 pts from Q2
A partial recovery — NPS bounced back 6.6 points. Bugs nearly disappeared from the detractor comments (7% vs 26% last quarter), suggesting reliability improved. However, onboarding spiked to 37%, tying with product gaps as the top complaint. This is the first quarter where "I can't get set up" became as loud as "the product is missing features." The shift is meaningful: it suggests the customer base had grown faster than CS capacity to activate them.
By TCA tier
Almost all detractors were in the <$1K tier (25 of 27). Onboarding dominated (10 comments) — these are low-investment firms who couldn't get set up and didn't have the resources to invest in consultants. This points to a structural gap: the standard onboarding package wasn't sufficient for customers who needed more hand-holding but weren't paying for it.
By lead volume
Mid-volume firms (25–74 leads) had the highest onboarding complaint rate (3 of 6 detractors). These firms are generating real intake volume but haven't mastered the platform — the most dangerous combination for churn. 0-lead firms complained about product gaps, consistent with inactive firms who explored the product and found it lacking.
By practice area
Estate Planning (8 detractors) split evenly between onboarding and product gaps. Family Law (4) was also heavy on onboarding. This is notable: Family Law's NPS was still +43 this quarter, but the onboarding signal emerging here foreshadowed its later decline. Business Law's NPS recovered to +40 — the one bright spot.
Top signal
"I feel like I am using a fraction of Lawmatics' capabilities, just because I don't know how to set it up or am unaware of what's available." This is the activation gap in plain language. The product may be capable — but customers aren't discovering that capability on their own.
Onboarding 37% Product gaps 37% UX 22%
2025 Q4 NPS +29.9 164 responses · 29 detractor comments ▲ 0.7 pts from Q3
Effectively flat quarter-over-quarter. NPS stabilized at ~30, a holding pattern heading into year-end. Onboarding complaints retreated; product gaps (38%) and ease of use (28%) returned as co-leaders. Support access held steady at 17%. The complaint profile was consistent with Q2 — feature gaps and UX friction — but without the bug spike that had hit Q2. This was the last stable quarter before 2026's deterioration.
By TCA tier
The <$1K tier continued to dominate (22 of 29), with UX and product gaps splitting evenly (7 each). Crucially, $6K–$12K TCA accounts registered their first detractor comment — a product gap complaint. This tier normally scores +58 NPS; any detractor signal there is worth tracking. Mid-tier ($1K–$3K) flagged support access more than product issues.
By lead volume
0-lead firms shifted their complaint to support access (3 of 10), consistent with inactive firms who reach out when stuck and can't get help. High-volume firms (200+) complained about product gaps (3 of 6) — firms generating real volume running into feature ceilings, especially reporting. The 25–74 tier had the most concentrated product gap signal (5 of 6 detractors).
By practice area
Estate Planning (11 detractors) stayed consistent with product gaps and UX. Family Law's NPS dropped to +34.6 — its third consecutive quarterly decline — with UX and support access as primary drivers. Criminal Defense hit +60 this quarter, masking the collapse that would come in Q1 2026.
Top signal
"Make it more intuitive and user friendly so that I don't have to hire a third party to create and edit my automations." The third-party dependency complaint — where firms need consultants to use the core product — was growing. That's a product usability failure, not a missing feature.
Product gaps 38% UX 28% Support 17%
2026 Q1 NPS +15.6 231 responses · 54 detractor comments ▼ 14.3 pts from Q4 2025
The sharpest single-quarter drop in the dataset. Response volume hit its highest point (231) while NPS fell 14 points. Detractor comments nearly doubled from 29 to 54. Three themes surged simultaneously: product gaps, ease of use, and bugs — all at 19–22%. Onboarding also rose (15%). This wasn't one problem getting worse; it was multiple problems hitting at once. March 2026 specifically recorded NPS of −7.0, consistent with a platform reliability event. The new-account cohort that entered the survey pool this quarter (−1.0 NPS) was the primary driver, but existing customers also deteriorated.
By TCA tier
The <$1K tier remained the largest bucket (38 of 54), but the $1K–$3K tier saw a major bug spike — 6 bug complaints vs. 0 in Q4. This is significant: mid-investment firms don't usually lead on bugs. It points to a platform reliability issue that cut across spend levels, not just low-engagement fringe accounts. Sales mismatch appeared exclusively in the <$1K tier (4 comments), all from new accounts.
By lead volume
The most telling pattern: high-volume (200+) firms drove the bug surge — 6 of 14 detractors in that bucket cited reliability. These are operationally dependent firms where downtime directly impacts client intake. Low-volume (1–24) firms had the highest sales mismatch rate (3 of 9) — new small firms who felt overpromised. Onboarding complaints concentrated in the 1–24 bucket, suggesting newly-signed small firms weren't being activated.
By practice area
Criminal Defense collapsed: NPS went from +60 in Q4 2025 to −20 this quarter. Their detractor comments cited ease of use and support access — not bugs — suggesting the redesign or a product change hit this practice area particularly hard. Estate Planning (20 detractors) was dominated by onboarding (6) and UX (4), a shift from prior product gap focus. Family Law's NPS fell to +12.5, continuing its multi-quarter slide.
Top signal
"Not force people to purchase 3 seats they don't know, be dishonest in your sales pitch meetings, and let people try the product before locking them into an annual contract." The only quarter where sales mismatch appeared as a measurable theme (4 comments, all new accounts). A leading indicator for future churn from this cohort.
Product gaps 22% Bugs 19% UX 19% Onboarding 15% Sales mismatch 7%
2026 Q2 NPS +13.1 168 responses · 40 detractor comments ▼ 2.5 pts from Q1
NPS continued to slip, reaching its lowest sustained level. The bug surge from Q1 partially receded, but product gaps returned to dominance at 38% — matching Q2 2025's peak. Pricing complaints hit their highest level (15%), a new signal that hadn't registered before. Onboarding held elevated (18%). The story of this quarter is that the reliability crisis of Q1 passed, but the underlying product and activation problems remain unresolved — and customers are now questioning value for money as a result.
By TCA tier
The <$1K tier (30 of 40 detractors) was dominated by product gaps (11) and onboarding (6). Pricing complaints emerged most strongly here — 5 of 6 total pricing mentions came from <$1K accounts. These are small firms who feel they're not getting enough for what they pay, and onboarding hasn't helped them see the value. The $1K–$3K tier was quieter but still flagged product gaps and UX.
By lead volume
High-volume (200+) firms shifted from bugs back to product gaps (5 of 9) and UX (4 of 9). The reliability crisis resolved, but feature gaps remain. Mid-volume (75–199) firms showed elevated bugs (2) and support access (2) — persistent issues for firms with active intake operations. Low-volume firms split between product gaps and pricing, consistent with inactive firms questioning whether to renew.
By practice area
Criminal Defense hit −50 NPS, its worst reading in the dataset. UX and bugs were the top themes — the redesign may be disproportionately disrupting how Criminal Defense firms manage consultations. Estate Planning (11 detractors) was dominated by product gaps and onboarding. Personal Injury remained the strongest segment at +67, suggesting simpler intake workflows that don't expose platform friction.
Top signal
"It has been extremely frustrating having everything we set up changing so regularly, having 100+ hours of set-up eliminated with changes to the system, and being nickeled and dimed with messaging fees." Three distinct grievances in one comment: product instability, onboarding ROI destruction, and pricing. This firm's experience is the clearest articulation of the 2026 customer problem.

Cross-cutting patterns
What the full arc tells you
Six-quarter synthesis across all dimensions

The <$1K TCA cohort is your NPS floor. They represent 67% of all responses and disproportionately drive every negative theme. Their complaint profile has been consistent for six quarters: product gaps, UX friction, and inability to get help. They're not a new problem — they've always been there. What changed in 2026 is that more of them entered the survey pool (new accounts) while existing ones grew louder about pricing and value.

High-volume firms (200+ leads) are your most important bellwether. When they complain about bugs — as they did in Q1 2026 — it signals a real reliability event. When they shift to product gaps — as in Q2 2026 — it signals feature ceiling. These firms have operational dependency on the platform and will churn if either problem isn't resolved. They're also your highest NPS segment overall, so protecting them is protecting the score.

Criminal Defense is a practice-area emergency. NPS went from +77 (Q2 2025) to −50 (Q2 2026) in four quarters. The UX and redesign complaints skew heavily toward this segment, suggesting the interface changes disrupted how Criminal Defense attorneys run consultations specifically. Worth a dedicated outreach campaign to the 31 Criminal Defense accounts in your book to understand what broke.

Onboarding complaints are structural, not seasonal. They appeared in every single quarter, peaking in Q3 2025 and remaining elevated through 2026. The profile is consistent: small firms (<$1K TCA, 1–24 leads) who paid for onboarding and couldn't get activated. Estate Planning and Family Law are the most affected practice areas. A 90-day activation check-in tied to actual platform usage metrics would catch these before they hit the survey.

Pricing as a complaint is new and worth watching. It barely registered before Q1 2026 (0–5%) and hit 15% in Q2 2026. It's concentrated in <$1K TCA accounts — firms that haven't found value and are now questioning the bill. If this continues trending up, it will compound churn in the next renewal cycle.
